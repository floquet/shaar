# shaar

**A gateway from flat spreadsheets to deterministic systems engineering and RAM workflows.**

## Structure
- `beamer/` — Modular LaTeX Beamer presentations (`main/`, `sections/`, `refs/`, `graphics/`)
- `db/` — Relational schemas (`schemas/`), recursive CTEs (`queries/`), and SQLite baselines
- `docs-guidance/` — Military reliability handbooks, standards, and reference guidance
- `python/` — Headless Python pipelines bridging Excel workbooks and SQLite
- `ram-materials/` — RAM notes, manifestos, FMECA structures, and sample datasets
- `scripts/` — Bash automation and audit helpers
